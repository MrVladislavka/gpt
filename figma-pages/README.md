# Figma Page Designs (Case Scenario)

This folder contains 6 **Figma-importable SVG wireframes**:

1. `registration-ui.svg`
2. `login-ui.svg`
3. `bank-transfer-ui.svg`
4. `customer-support-ui.svg`
5. `bank-admin-dashboard-ui.svg`
6. `loan-application-ui.svg`

## How to use in Figma
1. Open Figma and create a new design file.
2. Drag each SVG file onto a separate page/frame.
3. Rename pages to the required labels.
4. Apply brand colors/typography and interactive components.

## Nielsen’s Heuristics embedded in all pages
- **Visibility of system status**: progress indicators, state banners, status cards.
- **Match with real world**: domain language (account, beneficiary, transfer fee, ticket SLA).
- **User control and freedom**: cancel, back, save draft actions.
- **Consistency and standards**: repeated card layout, CTA placement, form patterns.
- **Error prevention**: validation regions, risk/limit checks, upload status warnings.
- **Recognition rather than recall**: selectors, pre-filled context, category tiles.
- **Flexibility and efficiency**: quick actions, support search, admin widgets.
- **Aesthetic/minimalist design**: clear hierarchy and whitespace.
- **Error recovery guidance**: inline messages and help links.
- **Help and documentation**: contextual help zones and support entry points.
