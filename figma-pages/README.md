# Figma Page Designs (Updated)

This folder contains 6 **Figma-importable SVG web/app pages** for the case scenario:

1. `login-ui.svg`
2. `bank-transfer-ui.svg`
3. `mobile-dashboard-app.svg` (mobile vertical dashboard/app)
4. `customer-support-ui.svg`
5. `bank-admin-dashboard-ui.svg`
6. `loan-application-ui.svg`

## Design characteristics
- Uses color hierarchy, text fields, cards, buttons, status banners, and action panels.
- Structured for usability and clarity with Nielsen’s Heuristics:
  - visibility of system status
  - match between system and real world
  - user control and freedom
  - consistency and standards
  - error prevention
  - recognition over recall
  - help and documentation

## Import into Figma
1. Create a new Figma file.
2. Create six pages/frames with matching names.
3. Drag each SVG into its page.
4. Convert groups/components as needed for interactive prototyping.
